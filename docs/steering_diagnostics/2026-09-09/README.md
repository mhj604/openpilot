# 그랜저 IG HEV 급커브 측정·분석 기록

2026-09-09까지의 기록을 보존하기 위한 문서 묶음이다. 차량 동작을 변경하는 패치나 새 튜닝값 배포가 아니다.

## 기준 차량과 버전

- 초기형 2019 그랜저 IG HEV, 순정 일반 크루즈 사용.
- 순정 SCC·레이더·전방 LKAS 카메라 없음. C2 자체 카메라는 사용.
- F4 Panda, Hyundai community safety, 실제 측정의 host 조향 상한 384.
- 두 최근 실차 기록의 C2 소스는 `4caf69d`다.
- 저장소의 기존 HEAD `c19df14`가 실차 측정에도 적용됐다고 혼동하지 않는다.
- 측정 당시 `OpkrMaxAngleLimit=140`, `AvoidLKASFaultEnabled=0`, Torque 제어였다. 이 값은 기록이지 권장 설정 또는 변경 명령이 아니다.

## 현재 결론

서로 다른 두 현상을 분리한다.

1. **2026-09-08 사용자 확정 우회전:** 약 36° 부근에서 최대 명령을 송신하고 MDPS도 활성 상태였지만 반응이 부족했다. 해당 핵심 구간의 원본 오류 비트는 모두 0이었다.
2. **2026-09-09 사용자 확정 우회전:** 약 105°에서 MDPS fault/fail이 발생하며 외부 자동조향 활성 상태가 내려갔다. 큰 수동 개입 신호는 약 0.81초 뒤에 나타났다. 큰 각도와 요청 활성 조건을 함께 보면 오류 네 건이 약 0.94~0.96초의 지속시간 패턴을 보였다. 정확한 제조사 내부 타이머 사양을 확정한 것은 아니다.

현재 C2의 일반 조향 오류 판정은 이번에 올라온 실제 `ToiFlt`를 놓쳤다. 고각도 요청 처리와 실제 오류 반영은 소프트웨어 수정 후보지만, 이것만으로 이전의 오류 없는 반응 부족까지 해결되거나 급커브가 완주된다고 보장하지 않는다.

경로계획기를 조향 능력에 맞추는 개선은 별도 후보다. 이번 교차로에서는 차선·도로 경계의 신뢰도가 낮아, 경로를 임의로 넓히는 수정의 근거로 사용할 수 없다. 게인·조향각·토크 상향, 운전자 우선권 또는 Panda/EPS 보호 완화를 처방하지 않는다.
