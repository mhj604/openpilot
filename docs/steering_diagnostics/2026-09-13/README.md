# 저속 급커브 후속 분석과 최종 판단

기존 주행 원본을 다시 집계하여 ‘사용 가능한 요청 여력이 남았는지’를 구분한 보존 문서다. **차량 코드 적용이나 새로운 튜닝값 배포가 아니다.**

먼저 [이전 기록 재분석 및 해결 범위](final-record-review-ko.md)를 읽는다. 기존 저속 보정 제안보다 이 문서의 원본 재집계를 우선한다.

## 핵심

- 9월 8일 사용자 확정 실패 구간은 90개 표본 모두 계산·송신 명령 크기가 384였다.
- 9월 9일 오류 직전 구간도 시각 조건을 만족한 162개 표본 중 155개가 계산 상한이었다. 송신 감소를 전부 튜닝상 여력으로 해석하지 않는다.
- 극저속에서 상한 아래인 후보 표본은 있었지만, 작은 각도의 짧은 구간이었다. 이를 급커브 완주 보정값의 근거로 쓰지 않는다.
- 저장된 EPS 펌웨어 식별 목록이 비어 있어, 차량별 정상 사양·업데이트를 특정하지 못했다.
- 따라서 저속 게인·마찰·적분의 추가 튜닝은 우선 해법으로 권하지 않는다. 근거 없는 완료 선언이나 보호 회피 패치는 하지 않는다.

과거 문서는 내용을 지우지 않고 남겼으므로 작성 당시 제안·미푸시 상태 등이 적혀 있을 수 있다. 그것이 이번에도 그대로 적용되거나 승인됐다는 뜻은 아니다. 9월 9일·10일 문서의 ‘이번 문서는 미푸시’는 각각의 작성 시점에 대한 설명이며, 이 폴더의 보존본은 이번 커밋에 포함된다.

주행 사진·좌표·CAN 원본·전체 설정·인증 정보는 공개하지 않는다. C2 실행 코드, Params, Panda 펌웨어, 크루즈 버튼, WebUI는 변경하지 않았다. 주행·테스트·QA·시뮬레이션·재부팅을 하지 않았다.
