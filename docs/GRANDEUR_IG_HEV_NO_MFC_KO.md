# 그랜저 IG HEV 무카메라·무SCC 작업 기록

## 차량 구성

- 대상 차량은 그랜저 IG 하이브리드다.
- 순정 전방 카메라(MFC), 레이더 및 SCC가 없다.
- 순정 일반 크루즈 컨트롤은 사용한다.
- Panda는 STM32F4 계열이며 F4 펌웨어를 사용한다.

## 적용된 기능

- 무카메라·무SCC 구성을 별도 차량 조건으로 처리한다.
- 순정 크루즈 메인 상태와 OP 횡제어 상태를 동기화한다.
- 일반 크루즈의 RES/SET 버튼 동작을 유지한다.
- C2 설정을 확인하고 변경할 수 있는 WebUI를 8086 포트로 제공한다.
- C2 비전 기반 전방 충돌 경고와 레이더 없는 차량용 반복 제동 경고를 끌 수 있는 설정을 제공한다.
- C2 경고 설정을 꺼도 차량의 순정 AEB 경고와 실제 제동 기능은 변경하지 않는다.

## 급커브 조향 진단

실차 기록에서 다음 사항을 확인했다.

- Panda의 현대차 조향 토크 안전 상한은 384다.
- C2 조향 상한을 409로 설정하면 384를 초과한 명령이 Panda 안전 검사에 걸릴 수 있으므로 384를 유지한다.
- 문제가 재현된 급커브에서는 384 포화에 도달하기 전에 차량이 덜 꺾였다.
- 자동조향 중 조향각이 약 91.8도에 도달하자 최종 조향 출력이 348에서 0으로 끊겼다.
- 당시 운전자 조향 개입은 없었으며, 이후 충돌 방지를 위해 운전자가 직접 약 111.2도까지 추가 조향했다.
- 원인은 `OpkrMaxAngleLimit=90` 조건에서 90도를 넘으면 `lkas_active`를 끄는 로직이었다.

이에 따라 이 차량 브랜치의 `OpkrMaxAngleLimit` 기본값과 파라미터 초기화값을 120도로 변경한다. Panda 조향 토크 상한 384와 상승·하강 속도 안전 제한은 변경하지 않는다.

## 기본 조향 설정

급커브 진단 과정에서 임시로 변경했던 조향 튜닝값은 다음 기본값으로 복원했다.

- `SteerActuatorDelayAdj=36`
- `TireStiffnessFactorAdj=85`
- `SteerThreshold=150`
- `LiveSteerRatioPercent=-5`
- `OpkrVariableSteerMax=0`
- `SteerMaxBaseAdj=384`
- `SteerMaxAdj=384`
- `TorqueKp=10`
- `TorqueKi=1`
- `TorqueKf=10`
- `TorqueFriction=65`
- `TorqueUseAngle=1`
- `TorqueMaxLatAccel=27`

장치에서 변경 전 Params 전체를 별도 백업한 뒤 위 값을 적용했다. 장치별 Params 백업과 접속 정보는 Git 저장소에 포함하지 않는다.
